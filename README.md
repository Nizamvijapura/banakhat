# જમીન બાનાખત Generator

GitHub Pages માટે તૈયાર mobile/iPhone-friendly web app.

## ચલાવવાની રીત
1. આ projectની files GitHub repositoryમાં upload કરો.
2. Repository → Settings → Pages.
3. Source તરીકે `Deploy from a branch` પસંદ કરો.
4. Branch `main` અને folder `/ (root)` પસંદ કરો.
5. Save કરો.
6. મળેલ `https://...github.io/.../` URL Safariમાં ખોલો.

## સુવિધાઓ
- 40 ગુંઠા = 1 એકર
- ગુંઠા × દરથી કુલ કિંમત automatic
- બાના અને બાકી રકમ
- 4 હપ્તા અને automatic તારીખ
- ખરીદનાર/વેચનાર/સાક્ષીઓની વિગતો
- ફોટો upload/camera
- touchscreen signature
- A4 print અને Save as PDF
- GPS/location feature નથી

નોંધ: કાયદેસર ઉપયોગ પહેલાં સ્થાનિક વકીલ/દસ્તાવેજ લેખક પાસે અંતિમ કરાર ચકાસાવો.
